# Repository guidance

- Write documentation in British/International English.
- Keep React as a peer dependency and external to the package bundle.
- Preserve strict TypeScript settings and the 80% coverage thresholds.
- Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build` when changing source or package configuration.
- Format with Prettier; use double quotes in JavaScript and TypeScript.
- Keep this library focused on reusable behaviour rather than UI components or styling.
